Sao lưu Google Drive (Đám mây)
Chưa kết nối
Tự động đẩy bản sao lưu lên thư mục Google Drive của bạn mà không cần tải file về máy.
❓ Hướng dẫn lấy Client ID miễn phí trong 2 phút
  1. Mở Google Cloud Console > Tạo 1 Project mới.
  2. Vào mục APIs & Services > Bấm Enable APIs > Tìm và Bật Google Drive API.
  3. Vào OAuth consent screen > Chọn External > Điền tên App (VD: KhoTruyen) và email của bạn rồi bấm Save.
  4. Vào Credentials > Create Credentials > OAuth client ID (Application type: Web application).
  5. Tại mục Authorized JavaScript origins, thêm: https://kyanh18.github.io (và http://localhost:8080 nếu thử nghiệm trên máy).
  6. Bấm Create, copy mã Client ID và dán vào ô trên!
